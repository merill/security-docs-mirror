# Security Foundations for SAF | Microsoft Learn

Security Foundations in the Microsoft Security Adoption Framework (SAF) provide the durable context behind modernization decisions.

They explain **why** specific security priorities matter, **how** they relate to Microsoft and industry guidance, and **where** to apply them across business scenarios, security disciplines, and technology implementation.

## What Security Foundations are

Security Foundations are the cross-cutting principles, lessons, and reference models that shape SAF guidance.

Use Security Foundations to:

- Align strategy, architecture, operations, and implementation decisions
- Prioritize high-impact actions without creating parallel frameworks
- Keep modernization efforts coherent as threats, technology, and business priorities evolve

## What this section covers

This section focuses on foundational topics that influence security decisions across SAF:

- Foundational security laws that capture durable realities about security controls, attackers, people, process, and technology to help teams test assumptions and make informed risk tradeoffs across SAF
- Zero Trust principles and their practical application
- Post-quantum readiness and cryptographic agility
- AI security considerations in modernization programs
- Security roles, responsibilities, and accountability models
- Microsoft Secure Future Initiative (SFI) lessons and priorities

## How to use Security Foundations

1. Start with your priority [business scenario](/en-us/security/zero-trust/security-adoption-business-scenarios-overview).
2. Use Security Foundations to guide decisions in each [security discipline](/en-us/security/zero-trust/security-adoption-discipline-overview).
3. Implement through [technology guidance](/en-us/security/zero-trust/deploy/overview) and [technical solutions](/en-us/security/zero-trust/implement-overview), then continuously refine through posture and SecOps feedback loops.
