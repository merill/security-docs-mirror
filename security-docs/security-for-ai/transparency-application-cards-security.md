# Application cards: Transparency documentation for Microsoft AI security products | Microsoft Learn

Application cards provide transparency into how Microsoft's AI-powered applications work. Each card covers the application's intended uses, capabilities, limitations, and the choices that influence its performance and behavior.

These resources support Microsoft's commitment to [responsible AI principles](https://www.microsoft.com/ai/principles-and-approach/) by providing the information you need to evaluate, deploy, and use AI applications in your environment.

## Microsoft Security Copilot

| Application card | Description |
| --- | --- |
| [Microsoft Security Copilot](/en-us/copilot/security/rai-faqs-security-copilot) | Covers the generative AI-powered security assistant that helps defenders investigate incidents, analyze threats, and manage security posture using natural language. |
| [Microsoft Security Copilot Agents](/en-us/copilot/security/rai-faqs-security-copilot-agents) | Describes autonomous AI agents that triage alerts, remediate vulnerabilities, and perform proactive security tasks across Defender, Microsoft Purview, Entra, and Intune. |

## Microsoft Purview

| Application card | Description |
| --- | --- |
| [Microsoft Purview Data Security Posture Management](/en-us/purview/data-security-posture-management-application-card) | Explains how AI identifies and surfaces data security risks to help organizations understand and improve their sensitive data protection. |
| [Microsoft Purview Data Security Investigations](/en-us/purview/data-security-investigations-application-card) | Details the AI capabilities that accelerate investigation of data security incidents involving sensitive information. |
| [Microsoft Purview Unified Catalog](/en-us/purview/unified-catalog-application-card) | Documents the AI features that automate data discovery, classification, and governance across your organization's data estate. |

## Microsoft Defender

| Application card | Description |
| --- | --- |
| [Microsoft Copilot in Defender](/en-us/defender-xdr/application-card-copilot-defender) | Addresses the embedded AI experience in Microsoft Defender XDR that assists security analysts with incident summarization, guided response, and threat analysis. |

## Microsoft Sentinel

| Application card | Description |
| --- | --- |
| [Microsoft Sentinel SIEM](/en-us/azure/sentinel/sentinel-siem-application-card) | Details the AI-driven capabilities that support threat detection, investigation, response, and proactive hunting across multicloud environments. |
| [Microsoft Sentinel MCP server](/en-us/azure/sentinel/datalake/sentinel-mcp-application-card) | Covers the AI capabilities of the Model Context Protocol server that enables natural language interaction with Microsoft Sentinel data. |
