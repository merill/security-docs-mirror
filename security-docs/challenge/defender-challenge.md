# Microsoft Defender Challenge | Microsoft Learn

![Security credentials banner with text that says defend skill up get certified.](/en-us/security/media/challenge/hero-credentials-with-text.png)

Complete the Microsoft Defender Skilling Challenge and submit an entry for a chance to win one of 500 50%-discounted SC-200 or SC-500 Microsoft Certification exam vouchers. Challenge entry period: July 20-August 21, 2026.

## About the challenge

The Microsoft Defender Skilling Challenge is your opportunity to deepen your expertise across the Microsoft Defender product family - including Microsoft Defender XDR, Microsoft Sentinel, and Microsoft Defender for Cloud. Work through curated learning modules, sharpen your security skills, and enter the sweepstakes for a chance to earn a discounted Microsoft Certification exam voucher toward the SC-200 or SC-500 exam.

## Learn Live: Remediating Threats Using Microsoft Defender

Join the free Microsoft Learn Live session **"Remediating Threats Using Microsoft Defender"** on **August 19, 2026**. This interactive session provides hands-on guidance on investigating incidents, remediating threats, and automating response actions across Microsoft Defender capabilities — a great complement to the challenge content.

[Register for the Learn Live event](https://reactor.microsoft.com/reactor/events/27333/)

## How to enter

No purchase necessary.

Steps:

1. Register for and complete the Microsoft Defender Skilling Challenge on Microsoft Learn before August 21, 2026 at 11:59 PM UTC.
2. After completing the challenge, submit your entry via the official sweepstakes entry form before the deadline.
3. If selected as a winner, you will be contacted by MindhubPro by Pearson VUE via email with your voucher code and redemption instructions.

## Win a certification exam voucher

Complete the challenge and enter the sweepstakes for a chance to win one of 500 50%-discounted Microsoft Certification exam vouchers. Eligible for the following exams:

- SC-200: Security Operations Analyst
- SC-500: Cloud and AI Security Engineer

## Explore Microsoft Defender learning topics

Get started with the topics covered in the challenge. Each card links to official Microsoft Learn content.

### Prepare for the SC-200 certification

Validate your skills in threat detection, investigation, and response using Microsoft Defender XDR, Microsoft Sentinel, and Microsoft Defender for Cloud. Start with a practice assessment to benchmark your readiness — then use the study guide to close any gaps before exam day.

[Learn more](/en-us/credentials/certifications/security-operations-analyst/?practice-assessment-type=certification)

### Prepare for the SC-500 certification

Get exam-ready for the Cloud and AI Security Engineer Associate certification. Build expertise in securing cloud workloads, managing AI security risks, and implementing Zero Trust principles across the Microsoft security platform.

[Learn more](/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/?practice-assessment-type=certification)

### Stay current with Microsoft Defender XDR

Keep pace with the latest innovations in Microsoft Defender XDR - new detection capabilities, unified incident response features, and expanded coverage across identities, endpoints, email, and cloud apps.

[See what's new](/en-us/defender-xdr/whats-new)

### Microsoft Sentinel best practices

Explore expert guidance for deploying and operating Microsoft Sentinel at scale. From workspace architecture and data connector strategies to analytics rules and incident response workflows - build a mature SIEM/SOAR practice.

[Explore best practices](/en-us/azure/sentinel/best-practices)

### Manage and respond to security alerts

Learn how to investigate, triage, and respond to security alerts in Microsoft Defender for Cloud. Understand how to work alerts in context, suppress false positives, and take automated or manual remediation actions to protect your cloud workloads.

[Learn more](/en-us/azure/defender-for-cloud/manage-respond-alerts)
