# Secure Future Initiative updates | Microsoft Learn

Customer-relevant progress and lessons from the Microsoft [Secure Future Initiative (SFI)](secure-future-initiative-overview) are now maintained in [What's new in Microsoft security guidance](../../saf/overview/whats-new).

SFI remains Microsoft's internal security transformation program. The [Microsoft Security Adoption Framework (SAF)](../security-adoption-model) provides customer-facing guidance informed by applicable SFI lessons, Zero Trust principles, and security best practices.

For a structured adoption path, see [Apply lessons from SFI](secure-future-initiative-adoption) and [How Microsoft Secure Future Initiative (SFI) informs SAF](../../saf/foundations/sfi/saf-mapping).
